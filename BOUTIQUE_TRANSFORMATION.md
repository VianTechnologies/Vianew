## ✨ Boutique Design Elements

### 1. Frosted Glass Trust Badges
```css
background: white/60
backdrop-blur: sm
border-radius: full
shadow: subtle
icons: colorful (accent, primary, rose)
```

**Effect:** Modern, iOS-style, premium

### 2. Gradient Text
```css
background: gradient(primary-600 to rose-500)
background-clip: text
text-fill: transparent
```

**Effect:** Eye-catching, modern, artistic

### 3. Elevated Cards
```css
hover: lift with shadow increase
border: subtle (gray-100)
border-radius: 2xl
padding: generous
```

**Effect:** Interactive, premium, depth

### 4. Soft Shadows
```css
shadow: soft, layered
no harsh drop shadows
subtle elevation
```

**Effect:** Refined, not heavy-handed
